# MCP сервер для индексации: как подключить SpeedyIndex к Claude

MCP сервер для индексации — это коннектор, который добавляет инструменты SpeedyIndex в Claude через протокол MCP. Он позволяет проверять индексацию страниц, запускать задачи индексации в Google и Яндекс, отслеживать позиции и проверять обратные ссылки прямо в чате с Claude. Такой сервер подходит SEO-специалистам и владельцам сайтов, которые хотят управлять рутинными операциями без переключения между вкладками.

Удалённый сервер работает по адресу `mcp.speedyindex.com/mcp` (Streamable HTTP, вход через OAuth). При подключении открывается страница SpeedyIndex, куда нужно вставить API-ключ из раздела API аккаунта — ключ не вводится в сам чат. Доступен и локальный npm-пакет `speedyindex-mcp` с 14 инструментами. Короткое видео ниже показывает весь процесс подключения в Claude.

## Что умеет SpeedyIndex MCP сервер

На удалённом сервере доступно 22 инструмента. Из них 15 только читают данные и не списывают токены; 7 изменяют состояние аккаунта и требуют подтверждения в Claude, если для инструмента не выбрана опция Always allow. Пять из этих семи тратят токены или кредиты: create_indexing_task, submit_single_url, create_index_check_task, create_backlink_check_task, rank_tracker_start_check. Создание проекта Rank Tracker и добавление ключевых слов бесплатны; запуск проверки — нет, стоимость заранее показывает инструмент rank_tracker_get_check_cost.

Инструменты для чтения включают: get_balance, list_tasks, get_task_status, get_task_report, get_backlink_check_status, get_backlink_check_report, rank_tracker_get_positions, rank_tracker_get_trend, rank_tracker_get_keyword_details, rank_tracker_list_projects, rank_tracker_search_locations, rank_tracker_get_limits, rank_tracker_get_check_cost.

Основные операции:
- Индексация: Google и Яндекс, до 10 000 URL за задачу. Задачи Google оплачиваются по модели pay-per-indexed: токены за не проиндексированные URL возвращаются автоматически. Доступен drip feed — распределение задачи на 2–30 дней.
- Проверка индексации: Google, Яндекс и Bing, до 10 000 URL за задачу; списки проиндексированных и не проиндексированных URL (для Google — с заголовками страниц).
- Проверка обратных ссылок: коннектор открывает страницы-доноры и проверяет, что они по-прежнему ссылаются на ваши домены: HTTP-статус, анкор, флаг nofollow, Moz Domain Authority и спам-скор по каждому донору; до 50 целевых доменов.
- Rank Tracker (Google, десктоп): проекты, до 5 регионов и 10 конкурентов, позиции и изменения с прошлой проверки, история трендов до 90 проверок, наличие AI Overview в выдаче и цитирование сайта.

Для проверки, попали ли страницы в индекс Google, используйте [массовую проверку индексации страниц в Google](https://speedyindex.com/proverka-indeksatsii-sayta-google/).

## Как подключить SpeedyIndex к Claude

Пошаговая настройка для Claude (web и desktop):
1. Откройте Plugins (claude.ai/plugins) или раздел Customize → Connectors, если у вас старая версия интерфейса.
2. Нажмите Add → Add custom connector, введите имя «SpeedyIndex» и URL `mcp.speedyindex.com/mcp`.
3. Нажмите Continue → Connect, на открывшейся странице SpeedyIndex вставьте API-ключ из раздела API аккаунта и подтвердите.
4. В чате нажмите «+» в поле ввода, выберите Connectors и включите SpeedyIndex.
5. Проверьте: задайте в чате «What is my SpeedyIndex balance?» — если Claude показывает количество токенов и кредитов, подключение работает.

Подробная [инструкция по настройке SpeedyIndex MCP-коннектора](https://speedyindex.com/mcp/) доступна на сайте SpeedyIndex. Обратите внимание: на бесплатном тарифе Claude можно добавить только один кастомный коннектор; на Team/Enterprise сначала владелец добавляет коннектор в Organization settings → Connectors, затем каждый участник подключается индивидуально.

Claude запрашивает подтверждение перед вызовом инструментов. Для доверенных инструментов можно включить Always allow. Кастомные коннекторы не проверяются Anthropic — подключайте только серверы, которым доверяете. Claude получает доступ только к тем данным, которые вы разрешили при входе.

Кроме Claude (web и desktop), SpeedyIndex MCP сервер поддерживается в Claude Code, Cursor и VS Code. Для Cursor используется файл `.cursor/mcp.json` или `~/.cursor/mcp.json`, для VS Code — `.mcp.json` (workspace) или команда MCP: Add Server. В Claude Code подключение выполняется командой `claude mcp add` с последующей аутентификацией через `/mcp`.

```bash
claude mcp add --transport http --scope user speedyindex https://mcp.speedyindex.com/mcp
```

## Сколько это стоит и что бесплатно

Сам коннектор бесплатный. Задачи оплачиваются токенами SpeedyIndex, подписка не нужна. Новым аккаунтам дают 100 бесплатных токенов. Чтение данных (баланс, списки задач, статусы, отчёты, позиции) не списывает токены. Создание задач индексации, проверок индексации, проверок обратных ссылок и запуск проверки позиций тратят токены — но для Google-задач действует pay-per-indexed: токены за URL, которые не попали в индекс, возвращаются автоматически. Drip feed позволяет растянуть задачу на 2–30 дней.

Безопасность: сервер не хранит базу данных, ключ сохраняется только внутри зашифрованного токена, токен доступа живёт 1 час, вход продлевается до 90 дней, смена ключа в аккаунте отзывает все подключения. Коннектор не выполняет платежи, не создаёт счета, не удаляет проекты или задачи.

## FAQ

### Какие задачи решает MCP сервер для индексации?

SpeedyIndex MCP сервер запускает индексацию в Google и Яндексе (до 10 000 URL), проверяет индексацию в Google, Яндексе и Bing, открывает страницы-доноры для проверки обратных ссылок и отслеживает позиции в Google с историей до 90 проверок.

### Сколько стоит использование SpeedyIndex MCP?

Коннектор бесплатный, оплачиваются только задачи токенами. Новым аккаунтам дают 100 бесплатных токенов. Чтение данных бесплатно; пять инструментов тратят токены, при этом Google-задачи возвращают токены за непроиндексированные URL.

### Как понять, что Claude подключён к SpeedyIndex?

Включите коннектор в меню «+» → Connectors и задайте в чате «What is my SpeedyIndex balance?». Если Claude вызывает инструмент get_balance и показывает токены и кредиты, подключение работает. Если нет — проверьте ключ, переподключите коннектор или удалите и добавьте его заново.
