# MCP сервер для індексації: підключення SpeedyIndex до Claude

MCP сервер для індексації SpeedyIndex — це конектор, який дозволяє Claude надсилати URL на індексацію в Google і Yandex, перевіряти індексацію в Google, Yandex та Bing, а також відстежувати позиції в Google. Він працює за відкритим стандартом Model Context Protocol (MCP), представленим Anthropic у листопаді 2024 року, і підключається до вашого облікового запису SpeedyIndex через OAuth.

Конектор безкоштовний, але завдання оплачуються токенами SpeedyIndex; нові акаунти отримують 100 токенів. На віддаленому сервері доступні 22 інструменти: 15 тільки для читання безкоштовні, 7 змінюють акаунт (з них 5 витрачають токени). Серед інструментів — створення завдань індексації, перевірка статусу і звітів, перевірка індексу до 10 000 URL, перевірка донорських сторінок на зворотні посилання, а також Rank Tracker для позицій Google із AI Overview. Короткий відеоогляд підключення SpeedyIndex до Claude — нижче.

## Як підключити SpeedyIndex MCP до Claude

Для Claude (web і desktop) потрібно відкрити Plugins і натиснути Add, потім Add custom connector. У полі URL вкажіть `mcp.speedyindex.com/mcp`, назвіть конектор SpeedyIndex і натисніть Connect. Відкриється сторінка входу SpeedyIndex, де потрібно вставити API-ключ з розділу API вашого облікового запису SpeedyIndex. Після підключення в чаті Claude натисніть «+» біля поля повідомлення, виберіть Connectors і ввімкніть SpeedyIndex. Для перевірки запитайте: «What is my SpeedyIndex balance?» — якщо Claude показує токени та кредити, конектор працює.

Детальний посібник із підключення SpeedyIndex MCP до Claude зібрано на сторінці [інструкція з підключення SpeedyIndex MCP](https://ua.speedyindex.com/mcp/).

Інші підтверджені клієнти: Claude Code, Cursor, VS Code. Для Claude Code використовуйте команду `claude mcp add`, потім усередині Claude Code виконайте `/mcp` → speedyindex → Authenticate. У Cursor додайте сервер у файл `.cursor/mcp.json` або `~/.cursor/mcp.json` з полем url `mcp.speedyindex.com/mcp`. У VS Code виконайте команду «MCP: Add Server» → HTTP і вставте ту саму адресу. Локальний варіант через npm: `npx -y speedyindex-mcp` з ключем у змінній `SPEEDYINDEX_API_KEY`.

```bash
claude mcp add --transport http --scope user speedyindex https://mcp.speedyindex.com/mcp
```

## Що вміє конектор

Індексація: Google і Yandex, до 10 000 URL за завдання. Для Google працює модель pay-per-indexed: токени за URL, які не потрапили до індексу, повертаються автоматично. Доступний drip feed — розподіл завдання на 2–30 днів. Перевірка індексу: Google, Yandex, Bing; до 10 000 URL за завдання; для Google у звіті є заголовки сторінок.

Backlink checker відкриває донорські сторінки, які ви вказали, і перевіряє, чи вони досі посилаються на ваші домени: HTTP-статус, анкорний текст, nofollow, Moz Domain Authority і spam score для кожного донора; можна вказати до 50 цільових доменів. Для масової перевірки, чи ваші сторінки потрапили до індексу Google, використовуйте [масовий чекер індексу Google](https://ua.speedyindex.com/perevirka-indeksu-google/).

Rank Tracker (Google, desktop) дозволяє створювати проєкти, додавати до 5 регіонів і 10 конкурентів, бачити позиції та зміни з останньої перевірки, історію тренду до 90 перевірок, а також чи з’являється Google AI Overview і чи цитує він ваш сайт.

## Безпека і підтвердження дій

Ключ API не вводиться в чат — він передається лише під час входу і зберігається на сервері виключно всередині зашифрованого токена. База даних на сервері відсутня. Токен доступу живе 1 годину, вхід оновлюється до 90 днів, а зміна ключа в акаунті анулює всі входи. Конектор не виконує платежі, не створює рахунки і не видаляє проєкти чи завдання.

Claude запитує підтвердження перед викликами інструментів; 7 інструментів, що змінюють акаунт, включно з 5, що витрачають токени, завжди запитують, якщо не встановлено «Always allow». Користувацькі конектори не верифіковані Anthropic — підключайте лише довірені сервери. На безкоштовному плані Claude можна додати один користувацький конектор; на Team/Enterprise конектор додає власник.

## Часті запитання

### Чи безкоштовний MCP сервер для індексації?
Конектор безкоштовний, але завдання з індексації та перевірок оплачуються токенами SpeedyIndex. 15 інструментів лише для читання безкоштовні. Нові акаунти отримують 100 токенів.

### Які клієнти підтримують SpeedyIndex MCP?
Підтверджені клієнти: Claude (web і desktop), Claude Code, Cursor і VS Code. Інших клієнтів у документації не заявлено.

### Як Claude запитує дозвіл на дії?
Claude запитує підтвердження перед викликами інструментів. Сім інструментів, що змінюють акаунт, включно з п’ятьма, що витрачають токени, завжди запитують, якщо не встановлено «Always allow» для довірених інструментів.
