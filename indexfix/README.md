# IndexFix Tools — downloadable files

`downloads/indexing-diagnostics-checklist-<lang>.pdf` — PDF checklist "Indexing problems: diagnostic checklist" (en, ru, uk, es, de, fr, vi).
The IndexFix Tools site copies these files into `/downloads/` at build time (see `DOWNLOADS_SRC` in the site's `build.py`).

`checklist-src/` — texts per language and the generator (`make_pdf.py`, Playwright → A4 PDF).
