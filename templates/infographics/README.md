# SpeedyIndex infographic templates (style v1.0, 18.10.2026)

Render: `npm i @fontsource/plus-jakarta-sans@5.0.20` in this folder, then `python3 gen.py` (series infographics, Pinterest 1000×1500 + X 1600×900) or `python3 svc.py` (service overview: 1080×1350, 1000×1500, 1600×900). Uses Playwright + Chromium.

Style rules: see Google Drive «стиль_инфографики_SpeedyIndex_v1.0.md».
